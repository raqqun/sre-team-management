# scratch/

Gitignored. Throwaway analysis — queries, one-off scripts, pasted output you
are still cleaning up.

Nothing here is read by anyone else, nothing here is a source of truth, and
nothing here survives. Paste the *output* into a document, not the script.

If a script is worth keeping, it does not belong in a documentation repo.
If its output is worth keeping, it belongs in [`reviews/`](../reviews),
[`incidents/`](../incidents), or [`runbooks/`](../runbooks) — with the query
that produced it recorded alongside the number, so the next person can re-run
it instead of trusting it.

Only this README is tracked; see [`.gitignore`](../.gitignore).
